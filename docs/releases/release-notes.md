# Release notes

### 2026-11-21

- 将 Agent 能力定义、Hub 会话准入策略、存储接口、节点续接语法及原生事件规范化拆成独立层；保留原有导入入口、会话身份与签名命令协议，便于新增 Agent 和替换实现。
- 前端完整解析公开的消息投递和采集来源契约，共享源控制组件；修复已验证 Hermes Runner 会话被页面隐藏续聊输入的问题，补充双端架构门禁与手机/桌面浏览器回归。

- 补齐 macOS / Windows Agent 原生命令解析：Windows 已知 npm 安装优先使用原生 exe / Node 脚本，保留 Unicode 与带引号指令，避免批处理转义。
- Pi 使用非交互 JSON 采集与精确会话续聊；ZCode、Hermes 从验证过 ID 和 cwd 的原生 SQLite 读取真实消息及工具，续聊保留脚本和本机 provider 参数。Hermes 工具工作目录隔离到任务配置；技能缓存目录不再误报为安装。
- 增加 macOS Agent CI、扩展 Windows 回归与真实子进程到 Hub 的工具证据测试；模型目录接管仍限定 Codex / Claude Code，未安装的 Windows Hermes 明确不可用。

### 2026-11-20

- 设置内容区统一标题、配置列表、状态标识、编辑器与保存操作区；模型 API 地址和凭据使用完整行，节点和工作区展示连接与路径信息，空状态和选中状态更清楚。
- 系统参数增加分组说明、整行可点击的开关和独立的生效提示，数据路径按名称与位置展示；账号、插件及集成管理统一布局与间距，手机表单和操作按钮提供 44px 点击区域。
- 外观设置改为浅色、深色、自动三张可预览的主题卡片，支持原生单选键盘操作、跟随系统与右上角主题菜单同步。

- 设置浮层支持点击遮罩关闭，沿用退场动画并保留聊天草稿；拖选、滑动、取消手势和右键不会误关。关闭后焦点返回原入口，手机隐藏入口回退到导航按钮。
- 设置搜索增加清空按钮与结果提示，支持 Enter 打开首个结果、Esc 先清查询及方向键分类导航；分类切换保留焦点，手机关闭与分类选择提供 44px 点击区域，浮层滚动不传到背景。
- 最近会话操作菜单同时只展开一个，外点、焦点移出、Esc 或 Tab 收起，支持方向键操作；手机 Esc 优先关闭菜单，收起侧栏时清除残留菜单状态。

### 2026-11-19

- 节点接入文件在切换设置分类、关闭浮层或编辑器替换后仍完成下载，不再因页面生命周期丢弃已轮换的凭据；设置页和主助手工作面板共用此行为，账号身份销毁后停止交付。
- 系统参数和节点展示配置的迟到保存响应不再覆盖重新加载后的新草稿，旧成功或失败提示也不会写入新编辑器。
- 集成配置加载失败后支持直接重试和重新进入分类恢复，加载中避免重复请求，成功后保持已有面板。

- 主助手读取远端会话时默认跳过重复的原始模型请求，直接读取消息、工具和状态；完整source记录仍可显式读取，两种模式均保留持久游标分页。

- 管理员主助手可直接查询会话控制命令历史和审计记录，不再依赖服务目录；补齐本地模型配置发现与切换入口，明确其不改变采集级别。已配置 Supervisor 的续聊和配置切换默认启用，显式关闭仍有效，项目管理委托不再逐次重复确认。
- 会话能力区分原生续接支持与身份绑定，缺少原生会话文件的纳管座席不再宣称可发送消息。ZCode 桌面宿主不再冒充单个对话；当前尚无 ZCode 桌面消息传输适配器，无法向其中的活跃对话注入消息。
- 常驻节点默认增量同步保留的原生会话文件；新增 ZCode 模型日志的消息/工具记录解析。历史同步复用加密 spool、脱敏和确认游标；HTTP 失败或未确认上传会重试，不以已读到文件末尾冒充同步成功。

### 2026-11-17

- 节点移除与服务注册、插件绑定在 SQLite 写事务中串行校验；服务与启用插件绑定会阻止移除，移除时清理已停用插件的当前缓存，迟到的旧凭据上报不能污染同名新节点。历史命令与回执继续保留。
- 明确未产生业务变更的管理版本冲突、节点引用拒绝可反馈给模型重新核对；检查点恢复沿用相同分类，不自动重放失败写入，未知结果与鉴权错误继续终止。
- 远端会话事件新增持久入库游标，统一助手、HTTP 与页面分页；不同事件流的相同或较小源序号不再漏读，迟到通知可刷新页面，旧数据原地迁移且源序号跳转仍可用。
- 设置读取显示“已读取管理信息”；仅成功保存运行配置或 hosts 后显示已保存与重启提示。

- 工作区设置在保存事务内重新校验绑定节点，修复节点并发移除后产生失效引用的问题。

- 主助手接入跨 VM Agent 会话发现、历史读取、消息派发、固定进程控制和原命令回执查询，沿用现有纳管校验与签名队列，避免将入队误报为远端任务完成。
- 管理员主助手新增项目总览和可发现的管理操作：统一设置、模型源 URL、节点接入与移除、插件、纳管、用量与命令诊断，以及已启用的记忆、定时检查、工作流和 MCP 管理。管理始终在 Hub 执行；节点登记与云 VM 生命周期明确区分。

- 主助手执行仓库文档中的相对命令前，先按项目目录转换路径，保留原测试范围与断言；已在同一修复版本完成的等价验证复用原回执，减少错误目录与重复测试带来的无效等待。

### 2026-11-16

- 模型流中的明确上游错误（`error.type=upstream_error`）复用现有生成重试，修复 HTTP200 流中断却因网关特有错误码未重试的问题；不重放工具，不将普通参数或鉴权错误一律重试。
- 主助手区分代码交付与 Git 发布；没有用户或仓库明确要求时，完成修改和验证后不额外暂存、提交或推送，避免无关 Git 操作和作者身份错误导致的额外调用。
- 未提交的模型生成遇到流中断、超时或明确瞬时错误时，按当前重试配置继续，先关闭原响应且不重放已执行工具；每次请求独立保留关联编号和未知费用，恢复正文替换当前部分草稿，前端显示具体重试原因。本地进度写入失败不会被误判为模型网络故障。
- 主助手可通过服务实际所在的标准 Node 读取日志，沿用签名、journal、回执和运行恢复；无日志能力时隐藏工具，工具卡片显示脱敏预览，读取失败不再误报空日志，Docker stderr 日志保留。
- 服务检查命令和审批单使用符合 ID 校验规则的随机标识，修复随机片段触发保留词校验时的偶发 500 或审批单无法读取。
- 标准 Node 接通显式配置的服务 inspect/restart 命令，沿用签名、审批和 journal 去重；主助手可读取原动作与审批状态，工具卡片区分等待审批、入队、完成和未知，避免将请求入队误报为操作完成。
- Docker 进程健康依据容器实际状态判断，修复 inspect 查询成功时将已退出、暂停容器误报为健康的问题；普通检查、复核和采集器保持一致，未识别输出保留未知。
- 修复参考记忆引用主助手名称时误跳过系统提示词的问题；首次请求始终带有主助手规则和当前能力，运行恢复使用原始检查点，避免重复注入。
- 明确命令每次从工作区根目录执行；子项目首次 Git 检查与测试发现使用显式相对目录，减少目录误判导致的无效调用。
- 普通主助手选择远程 VM 后，已配置的平台默认设置、会话与服务管理能力仍由 Hub 执行，工作区命令仍由 Node 执行；远程回执恢复不会重复之前已完成的设置保存。专用只读验收和 Workflow 合同保持原权限。
- 主助手先确认工作目录再操作文件，核对测试实际执行数量，并区分有限会话列表未命中与会话不存在；不把零项测试当作验证通过。
- 流式发布验收读取与 UI 相同的 SSE 快照，覆盖真实 HTTP 断流续读、原截止时间中断和异常响应关闭，避免仅凭终态后的历史事件判断实时反馈。
- 主助手区分使用 Agent Fleet 与开发 Agent Fleet；复杂项目任务按依赖推进，并恢复原目标中未完成的工作。
- 反馈与完成判断以实际观察到的阶段、回执、部署版本和功能验收为依据，避免把健康检查或计划误当成端到端通过。
- 线上只读任务验证了提交确认、流式文本与阶段反馈、目录工具结果、最终回复、会话恢复和退出后的会话撤销。
- 发布验收会再次读取 Run 状态并排除包含终态事件的整页进度，避免将任务完成后的缓冲输出误判为实时反馈。

### 2026-11-15

- 普通主助手默认不再因固定20个步骤或累计60000 Token终止；继续执行至模型完成、明确错误或用户取消，恢复时保留相同配置。显式任务合同的预算仍由调用方指定。
- 每轮回复的模型请求详情默认折叠为一条汇总，合计次数、Token、耗时与精确费用；展开可查看逐次请求，缺失数据明确标记，轮询保留展开状态。
- 工具卡片显示具体执行命令或文件路径，展开可查看结果预览和退出码；操作说明在调用前持久化，刷新后仍可恢复。
- Windows 备份落盘使用二进制文件句柄，避免密文末尾的 `0x1A` 被文本模式截掉；增加特殊结尾字节的跨平台回归。

- 远程助手只声明节点实际支持的工具，避免服务查询或产物操作被投递给没有对应执行器的 VM。
- Linux VM 命令通过独立 cgroup 管理全部后代，成功、超时和取消返回前清理脱离 session 的子进程；部署需要 `Delegate=yes`。Windows 沿用 Job Object。
- 节点接入配置在轮换凭据前验证 UTF-8 字节预算，安装器在写入文件前验证最终配置大小，避免下载成功后无法安装。
- 命令启动前控制通道瞬时失败最多尝试三次，保留原截止时间；失败原因与用户取消区分，已执行命令不自动重放。

### 2026-10-20

- Windows 台式机上的 Agent CLI 任务现在会稳定出现在本机与 Fleet 控制台中，并支持打开、继续对话和停止任务。
- Windows 后台探测与任务启动不再弹出可见的命令行窗口；权限不足、进程已退出或无法确认终止时，界面会保留真实状态，避免误报成功。
- Muse 对话现在会立即显示发送中的消息，并持续提示思考、输出或执行状态；任务完成后自动移除临时状态，恢复输入。

### 2026-10-19

- Windows 台式机上的 Agent CLI 任务现在支持更可靠的进程树发现、绑定和终止控制。
- 强制终止只有在确认整棵进程树已经退出后才会结束会话；无法确认时会保留运行态，避免控制台误报成功。
- Windows 权限不足、进程已复用和进程树读取失败会显示为不同的受控结果，方便继续处理异常机器。
