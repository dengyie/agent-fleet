# Release notes

### 2026-11-14

审查依据与回归场景见 [助手与设置页可靠性审查](../reviews/2026-11-14-assistant-settings-reliability.md)。

- 新会话创建由应用外壳同步地址与缓存身份；“开始新对话”打开独立草稿，后台提交完成不会改写当前设置页地址，返回原会话保留正在提交的消息。
- 从历史位置发送时定位到新消息；多行输入清空后自动收缩，明确拒绝后恢复原文和编辑高度。
- 手机模型报错不再自动打开遮挡对话的工作面板；错误与重新读取入口留在消息栏，运行详情按需打开。
- 设置账号切换时清理旧表单；加载失败不会把旧表单绑定到新账号，旧保存响应不会刷新或覆盖之后打开的账号编辑器。

### 2026-11-13

- 助手发送消息后会立即进入对话区并显示提交、排队和运行状态；新对话会先切换到会话页面，再等待模型结果。
- 模型请求结果待确认时保留原消息与运行记录，并提供重新读取状态的入口，避免误把上游 HTTP 503 当作可以重复执行的新请求。

### 2026-11-08

- 修复 GitHub CLI 插件把全新配置或退出最后一个账号后的“未登录”误报为“认证失败”的问题；主机选择始终以当前操作为准。

### 2026-11-07

- 客户端升级或重启后，从 Hub 的有效纳管记录恢复原会话身份、控制连接和采集桥；重新校验进程身份，恢复失败继续重试，成功后才确认接管新版本。
- probe 成功上报后正常退出仍能通过升级验收；旧回执不能代替本次接管。升级切换前记录事务意图，中断恢复核对实际链接并恢复原回滚目标。
- 长任务尚未结束时保留其正在使用的客户端版本，后续升级不会提前清理运行中的代码。
- 助手会完整读取运行事件分页；长运行结束和历史刷新后不再丢失第 100 条之后的工具卡片与结束事件。

### 2026-11-05

- 修复 1280×720 桌面高度下侧栏可调列表越过页脚的布局缺陷，并加入真实浏览器回归断言。
- 将 CI 视觉证据的 19 张原始 PNG 固化到仓库，视觉证据页为每张图提供全分辨率链接，并标明 HTTP 502 待确认结果夹具与生产验收边界。
- 校正六组架构图并交付按内容尺寸导出的 SVG/PNG、来源摘要与复现脚本，反映当前 lease、attempt、worker slot 和部署门禁契约。

### 2026-11-04

- Claude Code 新会话会按自身的明确会话标识关联原生记录，不会再误绑定其他工作区的历史会话；身份缺失、冲突或重复时保持未关联状态。
- 新增系统拓扑、数据/控制平面、任务状态机、身份解析、调度生命周期和发布验收六组可视化图，并固化 19 张桌面/移动端 UI 证据图的覆盖索引与 contact sheet。

### 2026-11-03

- Windows 工作区任务可通过已配置的沙箱启动器执行；任务超时会清理子进程，父进程提前退出也不会拖住输出回收。
- 终止 Agent 后，会话状态会同步结束；短暂存储故障或服务重启后可自动补全状态。
- 停止任务会先留出清理时间，再按需强制终止；节点进程启动时间统一为 UTC。

### 2026-11-02

- 节点状态上报在网络中断后可以安全重试，同一次上报不会重复增加历史记录或变更事件。
- 上报去重在服务重启与历史轮转后持续有效，写入中断后可恢复；证书或认证失败会明确结束，避免无效重试。

### 2026-10-20

- Windows 台式机上的 Agent CLI 任务现在会稳定出现在本机与 Fleet 控制台中，并支持打开、继续对话和停止任务。
- Windows 后台探测与任务启动不再弹出可见的命令行窗口；权限不足、进程已退出或无法确认终止时，界面会保留真实状态，避免误报成功。
- Muse 对话现在会立即显示发送中的消息，并持续提示思考、输出或执行状态；任务完成后自动移除临时状态，恢复输入。
- Muse 云端浏览器的活动面板会按最新任务状态更新，旧历史不会覆盖当前活动。

### 2026-10-19

- Windows 台式机上的 Agent CLI 任务现在支持更可靠的进程树发现、绑定和终止控制。
- 强制终止只有在确认整棵进程树已经退出后才会结束会话；无法确认时会保留运行态，避免控制台误报成功。
- Windows 权限不足、进程已复用和进程树读取失败会显示为不同的受控结果，方便继续处理异常机器。
