# M1.11 Disposable Provider Canary Implementation Plan

**Goal:** Prove the real stdlib `urllib` provider boundary against a disposable loopback HTTP server, including authentication placement, bounded response parsing, SSE/tool-call handling, stable HTTP failures, retries, timeouts, secret redaction, and one local Run worker path.

**Architecture:** Tests start a `ThreadingHTTPServer` bound to `127.0.0.1` on an ephemeral port. A small request handler returns deterministic OpenAI-compatible JSON or fragmented SSE and records only non-secret request metadata in memory. The provider is constructed without an injected transport and with `allow_network=True`; the worker integration enables the same gate explicitly in a temporary app. The fixture shuts down and joins its server before each test exits.

**Tech Stack:** Python stdlib `http.server`, `threading`, `urllib.request`, existing provider adapter, Flask test app, pytest.

**Global Constraints:** No production endpoint, VPS, external network, production credential, persistent process, or default-gate change. Bind only to loopback. Never print or persist the canary key. Keep provider errors and Run/event payloads bounded and secret-free. Do not add arbitrary URL or header support.

## Tasks

### Task 1: Disposable loopback fixture and non-stream canary

- [x] Add a test-only server helper with ephemeral loopback binding, deterministic routes, request capture without secret values, and guaranteed shutdown.
- [x] Exercise the actual default `UrllibTransport` for a non-stream completion.
- [x] Assert JSON payload/model/messages/tools, `Authorization` placement, assistant text, usage, loopback binding, and absence of the key from public response representations and captured metadata.

### Task 2: Streaming and failure canaries

- [x] Return deliberately fragmented SSE chunks containing text, structured tool-call deltas, usage, and `[DONE]`; assert normalized response order and arguments.
- [x] Return 401, 429, and 503 responses; assert stable bounded error classes and no response-body leakage.
- [x] Exercise one transient retry and one timeout through the real urllib path using only the fixture and bounded test timeout.

### Task 3: Worker integration

- [x] Enable provider network only on this disposable worker instance, run one queued Run, and assert success, result text, event safety, and no local fallback side effect.
- [x] Preserve the default provider-network gate as disabled in configuration.

### Task 4: Documentation and verification

- [x] Document M1.11 evidence, limitations, and the next engineering slice in the platform design and implementation plan.

## Exit Criteria

- Real `UrllibTransport` is exercised only against a loopback disposable server with the gate explicitly enabled in tests.
- API key is sent only as `Authorization` and is absent from `ModelResponse`, `ProviderError`, Run snapshots, events, and test-captured public metadata.
- Non-stream, fragmented SSE/tool-call, HTTP failure, retry, timeout, and worker integration cases pass.
- Production provider network, remote execution, service actions, and scheduler gates remain default-off.
