# M2.5 Komari Schema Fixture Contract Implementation Plan

> **For agentic workers:** Execute this plan task-by-task with focused tests after each task.

**Goal:** Define and verify a bounded, versioned, sanitized Komari node payload contract without claiming that it is the private fork schema until an export is supplied.

**Architecture:** Add a small `KomariPayloadContract` boundary inside the read-only Komari integration. It accepts the explicitly documented `schema_version: 1` envelope and the existing allowlisted node containers, preserves backward compatibility for already accepted unversioned injected fixtures, rejects malformed or unsupported envelopes before node normalization, and never exposes the raw payload. A checked-in JSON fixture represents only sanitized test data and is exercised through the existing loopback client and Incident sync path.

**Tech Stack:** Python standard library dataclasses/json, existing `KomariClient`/`normalize_nodes`, pytest, sanitized JSON fixture.

## Global Constraints

- The fixture is test-owned and contains no production endpoint, token, hostname, private IP, credential, or raw monitor dump.
- `schema_version: 1` is the only version accepted by the contract; unsupported versions fail closed with `unsupported_schema`.
- Existing unversioned injected requesters remain backward compatible while the private fork schema is still unknown.
- Malformed envelopes fail with `invalid_response` before empty-node normalization; monitoring records bounded unknown/source evidence.
- Unknown fields are ignored and never enter `KomariNodeSnapshot.detail`; raw payload and token never enter errors, DTOs, or incidents.
- No network, background sync, mutation, node registration, or production Komari access is added.

## Files and Interfaces

- Modify `hub/integrations/komari.py`: add `KomariPayloadContract`, bounded envelope validation, stable schema error codes, and contract-backed normalization.
- Modify `tests/test_platform_komari.py`: load the sanitized fixture and cover version acceptance, unknown-field dropping, malformed envelope rejection, unsupported version rejection, and Incident unknown evidence.
- Create `tests/fixtures/platform/komari_schema_v1.json`: sanitized versioned fixture with bounded node rows and harmless unknown fields.
