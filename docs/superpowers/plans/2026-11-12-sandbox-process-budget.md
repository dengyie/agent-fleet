# Sandbox Process Budget Implementation Plan

Parent: [development ledger](../../platform/development-completion.md). Related: [fixed-test launcher](2026-11-11-linux-workflow-launcher.md).

**Goal:** Run fixed tests on a shared Linux execution account without exhausting that account's process allowance before the isolation launcher starts.

**Architecture:** Linux RLIMIT_NPROC counts the real user's threads, so the generic backend cannot treat an early limit of 32 as a per-task budget. Make that host-user limit explicitly optional for dedicated-account deployments. Apply the normal 32-task limit inside the Linux launcher's new user namespace, immediately before executing the already validated test/reviewer command; keep CPU/memory limits, namespaces, filesystem mounts and seccomp intact.

**Tech Stack:** Existing Python 3.10+, resource, bubblewrap, pytest. No downloads, dependencies, production changes or development-branch commits.
