# M2.14 Komari Capture Verifier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task with verification checkpoints. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Validate a bounded, offline Komari response capture against the existing schema contract and produce only sanitized node evidence without opening a network connection or echoing raw payloads.

**Architecture:** Add a small pure helper beside the existing Komari client. It accepts bounded UTF-8 JSON bytes or a regular capture file, delegates structural validation and normalization to `normalize_nodes`, and returns a stable report containing only schema version, observed timestamp, node count, and sanitized node snapshots. Explicit capture versions must be integer `1`; unversioned legacy payloads remain compatible with the existing injected-requester contract. File reads reject symlinks, missing files, invalid UTF-8/JSON, and payloads above the existing `KomariClient.MAX_BODY_BYTES`; the helper never instantiates a requester or calls the network.

**Tech Stack:** Python standard library, existing `hub.integrations.komari` contract, pytest, JSON fixtures.

## Global Constraints

- Preserve the protected primary worktree and all existing user changes.
- Do not connect to Komari, VPS, provider, scheduler, Node, or production services.
- Reuse `KomariPayloadContract`/`normalize_nodes`; do not create a second schema or widen accepted payload fields.
- Report only bounded normalized node fields; never return the raw payload, token, secret, request URL, or raw error text.
- Keep the existing `KomariClient` network gate unchanged and default-off.
- Update the platform roadmap, M1.7 implementation record, canonical index, router, and project MOC through their existing Obsidian links.

- [x] **Step 1: Implement bounded decoding and stable error translation**

```python
MAX_CAPTURE_BYTES = KomariClient.MAX_BODY_BYTES

def verify_komari_capture_bytes(raw, *, observed_at=None):
    if not isinstance(raw, (bytes, bytearray)):
        raise KomariCaptureError("invalid_capture")
    if len(raw) > MAX_CAPTURE_BYTES:
        raise KomariCaptureError("capture_too_large")
    try:
        payload = json.loads(bytes(raw).decode("utf-8"))
    except (UnicodeDecodeError, ValueError, TypeError):
        raise KomariCaptureError("invalid_capture") from None
    try:
        rows = normalize_nodes(payload, observed_at=observed_at)
    except KomariError as exc:
        raise KomariCaptureError(exc.code) from None
    return {
        "ok": True,
        "schema_version": 1,
        "observed_at": rows[0].observed_at if rows else float(time.time() if observed_at is None else observed_at),
        "node_count": len(rows),
        "nodes": [row.as_dict() for row in rows],
    }
```
