# Deployable model reviewer implementation plan

**Goal:** Supply the missing production command-review peer and Linux launcher for coding-delivery, preserving the original immutable source, identity and verdict contract.

**Architecture:** A Hub-owned command entry point delegates to a small registered reviewer module that reuses the existing OpenAI-compatible provider and fixed report validator. The Linux launch mode reuses namespace mounts with explicit model-network access, a read-only source and package runtime, and only configured reviewer credential files. It creates no new Workflow/Run lifecycle. Every invocation performs one non-streaming model request with no retries or tools; rejected, truncated or unsupported input/output never becomes a passed verdict.

**Constraints:** Python3.10; UTF-8 without BOM; isolated feature worktree; no downloads, production writes, deployment, human acceptance or silent source omission. Config bytes are SHA256-pinned in both registered command and launcher; API key contents remain in a separate rotatable file. Whole UTF-8 source input has an explicit budget; binary and over-budget sources fail before provider I/O.
