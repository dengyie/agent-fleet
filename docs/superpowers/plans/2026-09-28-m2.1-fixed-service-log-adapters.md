# M2.1 Fixed Service Log Adapter Contract

Goal: replace the M1.12 test-only log reader seam with an adapter-owned, disposable contract for systemd, Supervisor, and Docker log reads while keeping real Node/VPS execution behind the existing default-off gates.

Architecture: FixedServiceLogReader accepts only the exact reconcile.service.logs envelope. fixed_log_argv owns the executable and all arguments for each supported adapter. The reader invokes subprocess.run with shell=False, bounded timeout and UTF-8 output, classifies timeout/unsupported/permission failures, and applies the command byte limit before the existing Node redaction boundary. No caller can supply a command, argv, unit, path, or shell fragment.

Files: tools/platform/services/logs.py, tools/platform/services/__init__.py, tests/test_platform_service_log_adapters.py, and M1.12 fencing tests.

## Exit Criteria

- Only adapter-owned argv can reach a service log process.
- Output is bounded before receipt persistence and remains subject to the shared Redactor.
- A reader failure cannot be interpreted as proof that the original command failed; post-check semantics remain remains_unknown.
- No production host, credential, external endpoint, or VPS was contacted.
