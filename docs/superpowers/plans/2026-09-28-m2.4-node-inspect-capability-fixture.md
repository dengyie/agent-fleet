# M2.4 Node Inspect Capability Fixture Implementation Plan

> **For agentic workers:** Execute this plan task-by-task with focused tests after each task.

**Goal:** Make the capability-scoped `NodeRuntime` assembly execute the existing fixed `reconcile.service.inspect` contract through a disposable local executable fixture, so a declared inspect capability is both visible and real.

**Architecture:** Extend the existing adapter-owned fixed-command runner with an optional test-only PATH prefix and let `NodeRuntimeConfig` carry a bounded inspect fixture prefix alongside the existing log prefix. `NodeRuntime` will construct `ServiceActionExecutor` only when `reconcile.service.inspect` is declared; the executor still owns adapter argv, uses `shell=False`, and exposes only bounded health metadata. Existing direct executor callers and all default gates remain unchanged.

**Tech Stack:** Python standard library, existing `ServiceActionExecutor`/`run_fixed_command`, `NodeRuntime`, Flask test client transport, pytest, temporary executable shims.

## Global Constraints

- `reconcile.service.inspect` remains unavailable unless explicitly declared in the Node capability set.
- Adapter-owned argv remains the only command construction path; no caller-supplied executable, argv, shell fragment, or service alias override is added.
- Fixture execution uses `shell=False`, bounded timeout, bounded output, and a temporary PATH prefix only.
- Public Node manifests and receipts never contain credential, workspace root, journal path, PATH values, or raw command output.
- Tests use temporary local files and in-process/loopback transport only; no production endpoint, VPS, service manager, provider, or real credential is used.
- Existing `NodeRuntime` log fixture, direct `ServiceActionExecutor`, and `run_fixed_command` callers remain backward compatible.

## Files and Interfaces

- Modify `tools/platform/services/base.py`: accept an optional bounded `path_prefix` for adapter-owned subprocess lookup while retaining the existing default environment.
- Modify `tools/platform/services/actions.py`: thread `path_prefix` through `execute_service_action` and `ServiceActionExecutor`.
- Modify `tools/platform/node_runtime.py`: add bounded `service_path_prefix` configuration and construct `ServiceActionExecutor` only for the inspect capability.
- Modify `tests/test_platform_node_runtime.py`: add inspect capability gating, temporary `systemctl`/`supervisorctl`/`docker` fixture execution, receipt redaction, and journal idempotency coverage.
- Modify `tests/test_platform_service_actions.py`: preserve and extend `shell=False`/PATH assertions.
- Update `docs/platform/agent-fleet-self-hosted-platform.md`, this plan, and canonical Obsidian agent-fleet records after verification.
